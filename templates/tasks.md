# Задачи среза NNN

Формат строки: `- [ ] T-NNN [P] [исполнитель] описание — путь:строка или тест — (FR-NNN)`.
`[P]` — можно делать параллельно. Исполнитель — haiku / sonnet / opus / человек. Каждая задача ссылается
на требование (FR-NNN / NFR-NNN) и называет тест (тестовый класс / функция), который закрывает задачу.

## Этап 1 — подготовка
- [ ] T-001 [sonnet] …

## Этап 2 — тесты (пишутся до кода и падают)
- [ ] T-010 [sonnet] …

## Этап 3 — реализация
- [ ] T-020 [sonnet] …

## Этап 4 — финальная проверка
- [ ] T-030 [opus] прохождение требований спеки (FR-NNN), регрессия прошлых срезов, проход в браузере, отчёт docs/reviews/TASKS-NNN.md
