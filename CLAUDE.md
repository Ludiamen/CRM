# Правила работы в репозитории портала ИТ-отдела

Собственный портал ИТ-отдела (сервис-деск + рабочее пространство) по образцу
«1С-Битрикс: Корпоративный портал», стек Django + HTMX + PostgreSQL, по SDD.
Полные правила — docs/sdd-process.md, принципы — docs/constitution.md.

## Жёсткие правила
- Код (`backend/`, `frontend/`, `deploy/`) пишется только под утверждённый
  план (`specs/NNN-*/plan.md`, статус «утверждён», подпись верна).
- Документы не утверждаешь: команду `sdd.py подписать` запускает человек.
  Твой потолок — «на-проверке» с отчётом в `docs/reviews/<id>.md`.
- Перед тем как объявить работу готовой: `python3 tools/sdd.py проверить`
  и `python3 -m unittest discover -s tools -p "test_*.py"`.
- Эталон описывает поведение Битрикса, но не копирует его код, вёрстку,
  иконки и тексты (инвариант «эталон-не-копия»). Слово `bitrix` в коде
  запрещено воротами.
- Каждое утверждение об эталоне — со ссылкой на источник `SRC-NN` из
  `docs/reference/sources.md`. «По памяти» не писать: неизвестное —
  маркер `[НУЖНО УТОЧНИТЬ: …]`, с ним документ не утвердить. Расшифровки
  сокращений не придумывать.
- Секреты — только `***`, в документах и отчётах тоже. Pre-commit хук
  `tools/check_secrets.py` подключается `tools/setup_git_hooks.sh`; ставь
  правило «секреты — только ***» в задание каждому исполнителю.
- Документы и интерфейс — по-русски; имена в коде — английские; имена
  файлов и каталогов — латиницей.
- `git push` делает человек.

## Разделение работы между моделями
- Haiku: сбор источников, опись модуля по шаблону, снимки экранов демо,
  сверка ссылок, формат.
- Sonnet: проверка описи Haiku по источникам, черновики спек, код и тесты по
  утверждённому плану, проход в браузере.
- Opus: конституция, ADR, карта возможностей и предложение MVP, архитектура,
  планы, проверка на воротах, сводка.
Черновик Haiku не идёт на подпись без проверочного прохода: в ГИС 2 из 5
утверждений первой инвентаризации Haiku были неверны, а здесь в 3 из 6
шаблонов он вписал несуществующие решения. Исполнителей запускать небольшими
партиями.
