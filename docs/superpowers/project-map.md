# Локальная карта проекта

Из корня репозитория запустите:

```bash
python3 tools/project_map.py
```

Откройте **http://127.0.0.1:8765/** на том же компьютере. Остановка — Ctrl+C.
Инструмент не предназначен для публикации в сети или работы через прокси.
Доступные маршруты — только `/` и `/api/map`; источники показываются путями
для открытия в репозитории, а не отдаются сервером. Сервер не имеет авторизации:
его данные доступны другим локальным процессам и пользователям машины.

Поиск ищет срезы, задачи и возможности; фильтр статуса относится к срезам.
Задачи и пути источников раскрываются под карточкой среза. «Готовое» означает
подтверждённую картой приёмку, в том числе с указанными открытыми исключениями.
«На приёмке» означает только наличие отметок при неподтверждённой приёмке,
а не факт запущенной процедуры приёмки; «предстоит» — отсутствие отметок
или чек-листа. Доля отметок не является готовностью релиза или оценкой труда.
У возможностей ссылка в спеке означает запланированное покрытие, не приёмку.

Во вкладке «Изменения» рабочая копия и история коммитов показаны отдельно.
Снимок пересчитывается при открытии, вручную и каждые 60 секунд; дата на странице
относится к последнему успешному чтению в этой вкладке. Если обновление не удалось,
страница сохраняет последний полученный снимок в памяти и показывает предупреждение.
После закрытия вкладки снимок не сохраняется. Git работает только локально, без fetch.
