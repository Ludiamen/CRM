# Реестр источников эталона

Каждое утверждение об эталоне («1С-Битрикс24: Корпоративный портал», коробка)
ссылается на источник отсюда. Проверку, что каждый `SRC-NNN` из документов
зарегистрирован, делает `tools/sdd.py`.

Диапазоны номеров: `SRC-001…099` и `SRC-101…199` — страницы в интернете
(группы модулей «люди и общение» и «работа и процессы»); `SRC-201…299` —
дистрибутив пробной коробки `/home/gpgr/Документы/bitrix24_encode`, главный
модуль 26.150.0 от 2026-02-19 (пути даны от `bitrix/modules/`, если не указано
иное); `SRC-401…` — снимки экранов тестового портала владельца (коробка,
2026-09-30…2026-10-03, дата снимка — в строке), файлы лежат вне репозитория в `/home/gpgr/Документы/bitrix-demo/screens/`:
на части снимков видны данные владельца стенда, поэтому в git они не кладутся.

## Надёжность источников

- **Дистрибутив — самый точный источник по коробке.** Языковые файлы
  `lang/ru/**.php` — это дословный текст интерфейса именно этой версии;
  страницы справки часто описывают облако или устаревшие редакции.
- **Дистрибутив перепроверен 2026-09-30.** Копия пропадала с машины, и
  владелец скачал пробную коробку заново в тот же каталог. Версия та же
  (главный модуль 26.150.0 от 2026-02-19, 95 модулей). Все 93 источника
  SRC-201…360 подтверждены повторно: файл на месте, опорная фраза в нём есть.
- **SRC-003 — обзорная страница из 14 пунктов.** Сверка показала, что на ней
  нет ни «лайков», ни упоминаний, ни форума, почты, типов отсутствий: из 51
  ссылки черновика на неё подтвердились около 15 (в основном про рабочие
  группы), остальные перепривязаны к дистрибутиву.
- **SRC-362 добавлен 2026-10-04** при подготовке среза 002 (Opus): импорт
  пользователей из CSV-файла в главном модуле проверка полноты не нашла. Опорные
  фразы сверены с дистрибутивом дословно.
- **SRC-363 добавлен 2026-10-05** при подготовке среза 003 (Opus): правила
  приёма почты модуля «Техподдержка» (с каких адресов письмо дописывается в
  открытое обращение, привязка к пользователю по адресу) в реестре не было.
  Опорные фразы сверены с дистрибутивом дословно. Тогда же уточнена строка
  SRC-262: ответственный по умолчанию и автозакрытие были в её файле, но не в
  описании.
- **SRC-364 добавлен 2026-10-05** (Opus) по требованию владельца к задачам
  (ADR-0009): режимы просмотра задач «Список», «Канбан», «Мой план», «Сроки»;
  тогда же SRC-365 — права постановки задач. Опорные фразы сверены с
  дистрибутивом дословно.
- **SRC-366…369 добавлены 2026-10-08** (Opus) по требованию владельца об умных
  напоминаниях (ADR-0010): напоминание о задаче, «почти просрочена» и
  «просрочена», канал «Push уведомления» и push-сервер эталона. Опорные фразы
  сверены с дистрибутивом дословно.
- **SRC-104 — документация API для разработчика**, а не поведение для
  пользователя: как источник возможностей открытых линий не используется.
- **Снимки SRC-538…704 — досъёмка пробелов REF-UX (2026-10-03).** Сняты
  партиями C1…C15 (часть — «с записями»: на стенде создавались и затем
  удалялись тестовые объекты), партии C1…C12 и C14…C15 проверены по кадрам
  отдельной моделью, кадры уборки C13 (SRC-702…704) — Opus, затем отдельной моделью при проверке версии 5; описания сужены
  до видимого. Пометка «по прогону» в строке значит,
  что сведение взято из хода съёмки (адрес, задержка, текст из DOM), а на
  кадре не видно. Номера снимков перенумерованы без пропусков: пропуски
  остались от неиспользованных номеров и от кадра, изменённого скриптом
  съёмки (исключён из реестра).
