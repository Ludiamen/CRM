## Назначение модуля

Модуль предоставляет возможность управления задачами, проектами и поручениями внутри организации, организации сроков выполнения, назначения соисполнителей и наблюдателей, отслеживания прогресса и эффективности работы сотрудников.

## Сущности

| Сущность | Что это | Атрибуты | Связь с другими |
|---|---|---|---|
| Задача | Единица работы с описанием, статусом и сроком | название, описание, автор, исполнитель, наблюдатели, статус, срок, приоритет, трудозатраты | может иметь подзадачи (родительская задача) |
| Проект | Совокупность связанных задач | название, участники, сроки, описание | содержит задачи |
| Шаблон задачи | Заготовка для создания задач | название, описание, поля по умолчанию | используется при создании новых задач |
| Чек-лист | Список контрольных пунктов внутри задачи | пункты, статусы выполнения | связана с задачей |

## Связи с другими модулями

- **CRM** — задачи могут быть привязаны к сделкам и контактам
- **Открытые линии** — обращения из контакт-центра могут порождать задачи
- **Диск** — прикрепление документов к задачам
- **Бизнес-процессы** — интеграция задач с автоматизированными процессами

## Возможности — кандидаты в карту эталона

| Возможность | Что делает | Используют | Источник |
|---|---|---|---|
| Создание и редактирование задач | Пользователь может создать новую задачу, заполнив название, описание, сроки и назначив ответственного | все сотрудники | SRC-101 |
| Назначение исполнителей и наблюдателей | Автор задачи назначает сотрудников для выполнения и добавляет наблюдателей для информирования | руководители, координаторы | SRC-101, SRC-250 |
| Управление сроками | Установка и отслеживание сроков выполнения задач | все пользователи задач | SRC-101 |
| Канбан-доска задач | Визуальное отображение задач по статусам в виде колонок (список, в работе, готово) | менеджеры проектов | SRC-101 |
| Шаблоны задач | Создание повторяющихся задач на основе готовых шаблонов | руководители процессов | SRC-101 |
| Чек-листы в задачах | Добавление контрольных пунктов для отслеживания подэтапов | все пользователи | SRC-250 |
| Отчёты по эффективности сотрудников | Анализ выполненных задач и затраченного времени | руководители, HR | SRC-101 |
| Иерархия задач (подзадачи) | Создание задач, зависящих от других задач | менеджеры проектов | SRC-101 |
| Синхронизация с Exchange | Отправка уведомлений о задачах на почту | системный администратор | SRC-101 |
| Пользовательские поля задач | Добавление дополнительных полей для хранения специфичной информации | администраторы | SRC-101 |
