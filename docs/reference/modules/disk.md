# Модуль эталона: Диск и документы

## Назначение модуля

Модуль предоставляет централизованное хранилище документов и файлов, управление доступом к документам, совместное редактирование документов в режиме реального времени, управление версиями и историей изменений.

## Сущности

| Сущность | Что это | Атрибуты | Связь с другими |
|---|---|---|---|
| Диск | Хранилище документов пользователя или группы | название, владелец, права доступа, квота хранилища | содержит папки и файлы |
| Мой диск | Личное хранилище пользователя | название (по имени пользователя), приватность, права | принадлежит одному пользователю |
| Общий диск | Хранилище, доступное группе пользователей или всем | название, администратор, права по ролям | может быть создан администратором |
| Диск группы | Хранилище, привязанное к группе пользователей | название, администратор группы, члены группы | связана с группой в портале |
| Папка | Директория для организации документов | название, описание, права доступа | содержит файлы и подпапки |
| Документ/Файл | Единица хранилища | название, расширение, размер, дата создания, автор, версии | может быть отредактирован, имеет историю версий |
| Версия документа | Снимок состояния документа в определённый момент | номер версии, дата, автор изменений, комментарий | может быть восстановлена из истории |
| Ссылка на документ | Публичная или приватная ссылка для доступа без входа | URL, срок действия, пароль, права (просмотр/скачивание) | используется для делегирования доступа |

## Возможности — кандидаты в карту эталона

| Возможность | Что делает | Используют | Источник |
|---|---|---|---|
| Мой диск | Персональное хранилище для каждого пользователя | все пользователи | SRC-106, SRC-259 |
| Общий диск | Совместное хранилище, доступное нескольким пользователям | команды, отделы | SRC-106, SRC-259 |
| Диск группы | Автоматическое создание хранилища для каждой группы (подключается при вступлении пользователя в группу) | администраторы, лидеры групп | SRC-106, SRC-259 |
| Загрузка и управление файлами | Загрузка, переименование, удаление и организация файлов в папки | все пользователи | SRC-106 |
| Совместное редактирование | Одновременное редактирование документов несколькими пользователями через встроенный редактор OnlyOffice | все пользователи | SRC-106, SRC-109, SRC-260 |
| История версий документа | Сохранение версии при загрузке нового файла и восстановление из истории версий | все пользователи, аналитики | SRC-106, SRC-259 |
| Управление доступом и правами | Установка прав на папки и документы (просмотр, редактирование, удаление) | администраторы, владельцы дисков | SRC-106 |
| Публичные ссылки на документы | Создание публичной ссылки на файл или папку для доступа без входа (можно запретить в настройках модуля) | все пользователи | SRC-106, SRC-259 |
| Интеграция с внешними сервисами | Совместное редактирование подключено через встроенный сервис OnlyOffice | администраторы | SRC-260 |
| Просмотр предпросмотр документов | Встроенный просмотр документов через Google Viewer без скачивания | все пользователи | SRC-260 |
| Поиск по содержимому | Файлы Диска участвуют в общем полнотекстовом поиске портала (модуль «Поиск») | все пользователи | SRC-106 |
| Квотирование хранилища | Администратор может включить ограничение объёма хранилища | администраторы | SRC-259 |
