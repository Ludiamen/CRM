## Назначение модуля

Календарь позволяет пользователю планировать встречи, совещания и события. Система поддерживает личные календари, календари групп и компании, бронирование переговорных. Встречи сопровождаются приглашениями и уведомлениями (создание, изменение, отмена).

## Сущности

| Сущность | Что это | Атрибуты (без типов) | Связь с другими |
|---|---|---|---|
| События | Встречи, совещания, планерки | название, время, место, участники, статус | приглашения, календарь |
| Календарь | Хранилище событий | тип (личный, группы, компании), владелец, участники | события |
| Переговорная | Комната для встреч | название, вместимость, оборудование, расписание | события |
| Приглашение | Приглас на событие | адресат, статус (принято/отклонено/ожидает), событие | событие |

## Связи с другими модулями

- **Рабочие группы (GROUPS)** — события группы отображаются в календаре группы
- **Живая лента (FEED)** — важные события календаря попадают в ленту
- **Мессенджер (IM)** — ссылка на встречу может быть отправлена в чат
- **Сотрудники (COMPANY)** — расписание отпусков интегрируется с личными календарями

## Возможности — кандидаты в карту эталона

| Возможность | Что делает | Используют | Источник |
|---|---|---|---|
| Личный календарь | Каждый пользователь может создавать события в своём календаре | все пользователи | SRC-004 |
| Календарь компании | Централизованный календарь событий компании, видим всем сотрудникам | администратор | SRC-004 |
| Календарь группы | У каждой рабочей группы может быть свой календарь с событиями | руководитель группы | SRC-004 |
| Создание встречи | Пользователь указывает время, участников, место проведения (в т.ч. переговорную) события | все пользователи | SRC-005, SRC-221 |
| Приглашение участников | При создании встречи указываются приглашаемые, они получают приглашение («Пользователь приглашает вас принять участие во встрече…») | организатор встречи | SRC-220 |
| Бронирование переговорной | При создании встречи можно выбрать переговорную; система проверяет занятость и вместимость («Количество участников превышает количество мест переговорной») | все пользователи | SRC-001, SRC-221 |
| Уведомления о встречах | Участники получают уведомления о создании, изменении и отмене встречи | участники | SRC-220 |
| Синхронизация с внешним календарём | Календарь портала может синхронизироваться с Google, Office365 (push-события) и по CalDAV — с iPhone/iPad (iCloud) | пользователи | SRC-222, SRC-223 |
| Планерки и собрания | Отдельный от обычной встречи режим: повестка дня (список вопросов), по каждому вопросу можно поставить задачу с ответственным и сроком прямо из повестки, после встречи ведётся протокол (в т.ч. вопросы вне повестки) | руководители, участники | SRC-356 |
| Планировщик занятости | При выборе времени встречи система показывает занятость приглашённых участников, чтобы подобрать время без пересечений | организатор встречи | SRC-357 |
| Публичная ссылка на свободное время (calendar sharing) | Сотрудник публикует ссылку на свои свободные слоты — приглашаемый сам выбирает удобное время встречи без переписки | все пользователи | SRC-358 |
