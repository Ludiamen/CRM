# Модуль эталона: Администрирование портала

## Назначение модуля

Модуль предоставляет управление конфигурацией портала, управление пользователями и их правами доступа, администрирование компонентов и модулей, мониторинг событий системы, резервное копирование и восстановление, управление уведомлениями и каналами коммуникации.

## Сущности

| Сущность | Что это | Атрибуты | Связь с другими |
|---|---|---|---|
| Пользователь портала | Сотрудник или администратор, имеющий доступ к портальным функциям | логин, пароль, имя, фамилия, отдел, должность, телефон, email, фото, статус активности, дата последнего входа | может входить в группы пользователей |
| Группа пользователей | Набор пользователей с общим набором прав | название, описание, члены, права и роли | используется для управления доступом |
| Роль пользователя | Набор прав и разрешений для выполнения операций | название, описание, разрешённые действия, прикреплённые пользователи | определяет возможности пользователя |
| Права доступа | Разрешение на выполнение конкретного действия в модуле | модуль, действие (создание, редактирование, удаление, просмотр), уровень доступа | назначаются пользователям или группам |
| Событие системы | Запись об действии в системе | тип события, пользователь, время, описание, затронутые объекты | логируется в журнал событий |
| Уведомление | Сообщение, отправляемое пользователю или администратору | тип, получатель, канал (почта, портал, SMS), текст шаблона | генерируется при возникновении событий |
| Резервная копия | Снимок состояния всей системы или отдельных компонентов | дата создания, размер, версия системы, содержимое (БД, файлы, конфигурация) | используется для восстановления |
| Параметр конфигурации | Настройка поведения системы | название, значение, область действия (глобальная, модуль, компонент) | определяет режим работы компонента |
| Лицензионный ключ | Документ, определяющий доступные функции | номер ключа, редакция (КП, облако), срок действия, модули | требуется для активации системы |

## Связи с другими модулями

- **Все модули** — администрирование затрагивает все функции портала (Задачи, CRM, Открытые линии, Бизнес-процессы, Диск, Техподдержка)

| Восстановление из резервной копии | Восстановление системы из резервной копии после сбоя или удаления | администраторы | SRC-108, SRC-266 |
| Управление настройками портала | Изменение основных параметров портала (название, логотип, цвета, язык) | администраторы | SRC-108 |
| Управление модулями | Включение/отключение модулей, установка дополнений | администраторы | SRC-108 |
| Создание пользовательских полей | Добавление полей для хранения дополнительной информации в объектах системы | администраторы | SRC-108, SRC-266 |
| Интеграция с AD/LDAP | Синхронизация пользователей портала с Active Directory/LDAP через отдельный модуль коробки | администраторы | SRC-108, SRC-268 |
| Управление мобильным приложением | Администрирование конструктора мобильного приложения портала через отдельный модуль «Мобильная платформа» | администраторы | SRC-269 |
| Мониторинг производительности | Отслеживание параметров производительности сайта («Монитор производительности») | администраторы | SRC-108 |

| CAPTCHA на формах без входа | Проверочное слово с картинки защищает открытые формы (регистрация, вход) от автоматических/ботовских обращений | система | SRC-312 |
| Политика паролей и сессий | Требования к паролю (длина, состав символов, запрет повтора), срок действия пароля, тайм-аут сессии, число попыток входа до блокировки — настраиваются администратором | администраторы | SRC-313 |
| Проактивная защита от атак и заражений | Проактивный фильтр (WAF) от известных веб-атак, веб-антивирус, сканер безопасности файлов и контроль активности посетителей — отдельно от 2FA и IP-стоп-листа | администраторы | SRC-314 |
| Статистика поисковых запросов | Отчёт о том, что искали пользователи на портале и куда попадали, включая запросы без результата | администраторы | SRC-315 |
