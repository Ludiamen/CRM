# Модуль эталона: Задачи и поручения (наблюдения для среза 010)

     поручения входят в модуль задач (SRC-001). Поэтому здесь собрано только то, что подтверждено источниками,

## Назначение

По SRC-001 модуль эталона называется «управление задачами и поручениями»: поручения не выделены в отдельный
модуль, а входят в модуль задач. В портале ИТ-отдела поручения — отдельный модуль (решение владельца, CAP-116,
ADR-0013), потому что у поручения своё основание, контролёр, отчётные даты и правила контроля.

## Что подтверждено источниками

| Наблюдение | Источник | Что берём в срез 010 |
|---|---|---|
| Задачи и поручения — один модуль эталона | SRC-001 | отдельный модуль портала, но связь с задачами (поручение раскладывается на задачи) |
| У задачи есть наблюдатели | SRC-250 | соисполнители и контролёр видят поручение и получают уведомления |
| Напоминание «за N дней» до крайнего срока, по дате, по email или мгновенным сообщением | SRC-366 | лестница напоминаний по длине срока, каналы из среза 004 |
| Карточка с полями постановщика, исполнителя, срока, статуса и лентой событий | REF-UX UX-03, SRC-429 | карточка поручения: основание, контролёр, отчётные даты, отчёты, история переносов |
| Реестр с пресетами и фильтрами, колонками, страницами 20/50 | REF-UX UX-04, SRC-427, SRC-428 | реестр поручений: мои, на моём контроле, подчинённых, просроченные, по основанию |

## Чего в описях эталона нет

- Отчётных дат, отличных от срока исполнения, и отчёта к каждой дате — **источниками не подтверждено**.
- Принятия отчёта контролёром и возврата на доработку — **источниками не подтверждено**.
- Снятия с контроля только контролёром — **источниками не подтверждено**.
- Переноса срока по запросу с согласованием и сохранением исходного срока — **источниками не подтверждено**.
- Отчёта по исполнительской дисциплине и выгрузки в Excel — **источниками не подтверждено**.

Эти правила задаёт ADR-0013 (ответы владельца 2026-10-21), а не эталон. Опись не выдаёт их за наблюдения
Битрикса.

## Источники

SRC-001, SRC-250, SRC-366, SRC-427, SRC-428, SRC-429; приёмы интерфейса — REF-UX UX-03, UX-04.
