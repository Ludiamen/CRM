# Модуль эталона: Техподдержка

Версия 3 сверена 2026-11-24 с открытым текстом страницы курса администратора «Организация работы службы
поддержки» (SRC-110): цитаты ниже приведены по этой странице дословно. Утверждения, которых в проверенных
источниках нет, помечены как неизвестные, а не выданы за факт эталона.

## Назначение модуля

Реестр описывает SRC-107 так: «организовать на вашем сайте систему обращений посетителей» (REF-SRC, SRC-107).
Страница курса (SRC-110) называет задачи модуля дословно: «организовать на сайте систему обращений сотрудников
компании к группе сотрудников, отвечающих за консультирование и техподдержку», «назначать ответственных за
решение тех или иных вопросов», «управлять уровнями технической поддержки», «отслеживать время и эффективность
рассмотрения обращений», «анализировать оценку получаемых ответов» (SRC-110). Для полноценного управления
модулем нужны права группы «Администраторы» (SRC-110).

## Экраны и элементы интерфейса

- Интерфейс техподдержки состоит из двух частей — публичной и административной; клиенты пользуются публичной,
  сотрудники — административной (SRC-110).
- В административной части есть пункты «Обращения», «Работа с обращениями», «Графики», «Расписания и
  исключения», «Группы», «Спецобращения» (SRC-110 — навигация курса). [НУЖНО УТОЧНИТЬ: что именно содержит
  каждый пункт — уроки «Графики», «Расписания и исключения», «Спецобращения» не прочитаны.]
- Уровень поддержки задаётся в административном интерфейсе и содержит «Время реакции на сообщение клиента»
  (SRC-263).
- Форма обращения позволяет установить ответственного по умолчанию по выбранной категории или SLA и включить
  автозакрытие обращения при отсутствии ответа клиента через заданное число дней (SRC-262).
- Справочник техподдержки — списки значений; частые ответы — заготовленные тексты (SRC-262, SRC-265).

## Сценарии

- **Обращение и SLA.** Пользователь создаёт обращение (через форму на сайте, письмом или звонком — SRC-110);
  обращение рассматривается по параметрам SLA, назначенного его группе пользователей (SRC-110).
- **Ответ.** Ответ на обращение публикуется в Bitrix Framework и отсылается пользователю по электронной почте
  (SRC-110).
- **Смена ответственного.** Ответственных за решение вопросов назначают; сотрудник работает с обращениями, где
  он указан ответственным, и получает извещения о них (SRC-110).
- **Автозакрытие.** В форме обращения включается закрытие при отсутствии ответа клиента через заданное число дней
  (SRC-262).
- **Оценка ответов.** Оценку получаемых ответов можно анализировать (SRC-110); оценка ответов есть среди
  справочников (SRC-262).

## Права и роли

- Штатные, не настраиваемые роли: «Клиент техподдержки» — создаёт и редактирует свои обращения и получает
  почтовые извещения о событиях своего обращения; «Сотрудник техподдержки» — работает с обращениями, где он
  ответственный, и получает извещения о них; «Администратор техподдержки» — редактирует справочник и любое
  обращение, назначает ответственных, получает извещения обо всех обращениях (SRC-110).
- Участнику группы поддержки можно отдельно разрешить читать тикеты группы и получать уведомления группы
  независимо от назначения ответственным (SRC-327).

## Настройки администратора

- Уровни поддержки (SLA) с временем реакции на сообщение клиента (SRC-263).
- Справочник техподдержки: категории, критичности, сложности, источники, оценки ответов (SRC-262).
- Частые ответы и уровень поддержки по умолчанию для купонов (SRC-265).
- Автозакрытие обращения при отсутствии ответа клиента через заданное число дней (SRC-262).

## Уведомления

- Почтовые извещения о событиях обращения: клиенту — обо всех событиях своего обращения, сотруднику — об
  обращениях, где он ответственный, администратору — обо всех обращениях (SRC-110).
