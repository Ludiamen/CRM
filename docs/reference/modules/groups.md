## Назначение модуля

Рабочие группы (GROUPS) организуют совместную работу сотрудников над проектами и задачами. Группа может быть открытой для всех или закрытой для приглашённых участников. Система поддерживает экстранет — область для совместной работы с внешними пользователями (партнёры, подрядчики).

## Сущности

| Сущность | Что это | Атрибуты (без типов) | Связь с другими |
|---|---|---|---|
| Рабочая группа | Проект или команда | название, тип (открытая/закрытая), участники, руководитель, описание | документы, чаты, события |
| Участник группы | Член команды | роль (автор, администратор, модератор, участник) | рабочая группа |
| Внешний пользователь | Партнёр или подрядчик в экстранете | учётная запись, доступные группы, статус активности | экстранет группы |

## Связи с другими модулями

- **Документы и файлы (Диск)** — рабочая группа имеет хранилище файлов для совместной работы
- **Календарь (CALENDAR)** — у группы может быть календарь событий
- **Мессенджер (IM)** — группе может быть автоматически создан чат
- **Живая лента (FEED)** — события группы попадают в ленты участников
- **Задачи и проекты** — задачи группы отображаются в интерфейсе группы

## Возможности — кандидаты в карту эталона

| Возможность | Что делает | Используют | Источник |
|---|---|---|---|
| Открытая группа | Любой сотрудник может присоединиться к открытой группе и видеть её контент | все пользователи | SRC-003 |
| Закрытая группа | Группа видна только приглашённым участникам, требуется приглашение для присоединения | администратор портала | SRC-003 |
| Создание группы | Сотрудник создаёт новую рабочую группу для проекта | пользователи с правом создания | SRC-003 |
| Управление участниками | Администратор группы приглашает/удаляет участников, назначает роли | администратор группы | SRC-003 |
| Совместное редактирование документов | Участники группы могут вместе редактировать документы в группе | участники группы | SRC-003 |
| Экстранет — внешние пользователи | Можно создать экстранет для работы с внешними партнёрами | администратор портала | SRC-003 |
| Доступ внешних пользователей | Внешний пользователь может присоединиться только к группам экстранета | внешний пользователь | SRC-003 |
| Группа в экстранете | Группа в экстранете содержит информацию для совместной работы с партнёром | администратор экстранета | SRC-003 |
| Ограничение прав внешних пользователей | Администратор группы может запретить внешним пользователям видеть определённые разделы | администратор группы | SRC-003 |
