## Назначение модуля

Модуль предоставляет возможность автоматизации бизнес-процессов организации, управления всеми этапами процесса и необходимыми для его исполнения действиями, создание и применение шаблонов для повторяющихся операций.

## Сущности

| Сущность | Что это | Атрибуты | Связь с другими |
|---|---|---|---|
| Бизнес-процесс | Зафиксированная последовательность действий и этапов | название, описание, этапы, условия переходов, действия, статус | может быть применён к элементам инфоблоков и другим сущностям |
| Этап процесса | Отдельный шаг в бизнес-процессе | название, действия, условия завершения, роль исполнителя | часть процесса |
| Действие | Операция, выполняемая на этапе | тип (создание задачи, отправка уведомления, вызов вебхука и т.п.), параметры | часть этапа |
| Условие переходов | Логика определения следующего этапа | условие, результирующий этап | используется для разветвления процесса |
| Шаблон процесса | Готовый процесс для многократного использования | название, описание, процесс | может быть применён к разным сущностям |
| Задание по процессу | Активное выполнение этапа процесса пользователем | исполнитель, статус, срок, результат | выполняется в контексте процесса |
| Инфоблок/Универсальный список | Сущность, к которой применяется процесс | название, элемент, статус процесса | может быть привязана к одному или нескольким процессам |

## Связи с другими модулями

- **CRM** — интеграция процессов с управлением сделками и контактами
- **Задачи** — создание задач на основе этапов процесса
- **Открытые линии** — интеграция обращений с процессами обработки
- **Универсальные списки** — применение процессов к элементам списков
- **Диск** — управление документооборотом через процессы

## Возможности — кандидаты в карту эталона

| Возможность | Что делает | Используют | Источник |
|---|---|---|---|
| Визуальный конструктор процессов | Создание и редактирование процессов через графический интерфейс без программирования; в коробке за это отвечает отдельный компаньон-модуль «Дизайнер бизнес-процессов» | администраторы, бизнес-аналитики | SRC-105, SRC-256 |
| Управление этапами процесса | Определение последовательности этапов и параметров шаблона, автозапуск при добавлении или изменении элемента | администраторы, бизнес-аналитики | SRC-256 |
| Автоматическое выполнение действий | Встроенные демо-шаблоны показывают действия «Почтовое сообщение» и постановку задачи на утверждение документа; отдельное действие может вызвать внешний REST-сервис | система, администраторы | SRC-258 |
| Создание шаблонов процессов | Сохранение готовых процессов для переиспользования | администраторы | SRC-105 |
| Применение процесса к элементам | Запуск процесса при создании или редактировании элемента инфоблока | система, пользователи | SRC-105 |
| Управление заданиями по процессу | У каждого этапа процесса есть «Задание» с исполнителем и статусом, его можно делегировать другому пользователю | исполнители, супервизоры | SRC-257 |
| История процесса | «История выполнения бизнес-процесса» — журнал запуска, завершения, отмены и ошибок каждого действия | аналитики, супервизоры | SRC-257 |
| Триггеры и события | Вкладка «Триггеры» в параметрах шаблона процесса | система, администраторы | SRC-256 |
| Вызов внешних сервисов (веб-хуки) | Действие процесса может обратиться к внешнему REST-сервису; отдельно в CRM есть триггер на входящий вебхук | администраторы, разработчики | SRC-258 |
| Условные переходы и параллельные действия | В движке есть условие для ветвления, а демо-шаблон «Экспертная оценка» рассылает задание сразу группе участников и ждёт мнения от каждого | администраторы, бизнес-аналитики | SRC-257, SRC-258 |
