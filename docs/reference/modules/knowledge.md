## Назначение модуля

База знаний (Wiki) служит корпоративным хранилищем документов, инструкций, техниче­ских заданий и накопленных знаний. Сотрудники совместно создают и редактируют статьи, ис­пользуют теги для быстрого поиска информации. Система позволяет организовать структурированное хранилище информации, доступное всем сотрудникам.

## Сущности

| Сущность | Что это | Атрибуты (без типов) | Связь с другими |
|---|---|---|---|
| Статья | Документ в базе знаний | название, текст, автор, время создания, версия, теги | рубрики, комментарии |
| Рубрика | Раздел базы знаний | название, описание, иерархия | статьи |
| Версия статьи | Сохранённая версия документа | номер версии, автор, время, изменения | статья |
| Комментарий | Обсуждение к статье | автор, текст, время | статья |

## Связи с другими модулями

- **Живая лента (FEED)** — новые и обновленные статьи базы знаний могут попадать в ленту
- **Рабочие группы (GROUPS)** — каждая группа может иметь свою базу знаний или раздел

[НУЖНО УТОЧНИТЬ: входит ли база знаний в общий полнотекстовый поиск портала — источник SRC-215 (компонент поиска Wiki) говорит, что поиск идёт «в этом вики-проекте», то есть отдельно от общего поиска сайта; прежнее утверждение о едином поиске не подтвердилось]

## Возможности — кандидаты в карту эталона

| Возможность | Что делает | Используют | Источник |
|---|---|---|---|
| Создание статьи | Пользователь с правом создаёт новую статью базы знаний («вам предстоит её создать») | пользователи с правом | SRC-210 |
| Совместное редактирование | Право «Создание/изменение страниц» выдаётся группе, а не одному человеку — статью может править любой участник с этим правом | все пользователи с правом | SRC-227 |
| Версионирование | По каждой странице ведётся история, можно вернуться к любой предыдущей версии | автор, модератор | SRC-210 |
| Теги для поиска | Статьи помечаются тегами, по которым легко найти нужную информацию | все пользователи | SRC-213 |
| Облако тегов | На странице базы знаний отображается облако тегов (компонент «Вывод ключевых слов») | все пользователи | SRC-214 |
| Рубрики базы знаний | Статьи организованы по категориям | администратор, автор | SRC-211 |
| Поиск в базе знаний | Строка поиска ищет только «в этом вики-проекте», не по всему сайту | все пользователи | SRC-215 |
| Комментарии к статьям | Пользователи могут вести обсуждение статьи | все пользователи | SRC-212 |
