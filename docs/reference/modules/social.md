## Назначение модуля

Социальные сервисы объединяют инструменты для общения и взаимодействия сотрудников: опросы, благодарности и награды, форум для обсуждений, блоги для публикации статей, фотогалереи для размещения изображений. Система позволяет организовать корпоративное сообщество и повысить вовлечённость сотрудников.

## Сущности

| Сущность | Что это | Атрибуты (без типов) | Связь с другими |
|---|---|---|---|
| Опрос | Вопросник для сбора мнений | название, вопросы, варианты ответов, начало, конец, видимость | голоса, результаты |
| Благодарность | Награда за достижение | к кому, за что, кто дал, значок, время | профиль сотрудника |
| Тема форума | Обсуждение в форуме | название, автор, сообщения, статус, модератор | форум, сообщения |
| Блог | Канал публикаций автора | название, автор, описание, записи | записи, комментарии |
| Запись блога | Статья в блоге | название, текст, автор, время, комментарии, рейтинг | блог |
| Фотогалерея | Альбом фотографий | название, автор, описание, фотографии | альбомы |

## Связи с другими модулями

- **Живая лента (FEED)** — записи блогов, опросы, благодарности попадают в ленту
- **Рабочие группы (GROUPS)** — в группе может быть форум для обсуждений
- **Профиль сотрудника (COMPANY)** — полученные значки благодарности отображаются на профиле

## Возможности — кандидаты в карту эталона

| Возможность | Что делает | Используют | Источник |
|---|---|---|---|
| Создание опроса | Администратор или модератор создаёт новый опрос с вопросами и вариантами ответов | администратор, модератор | SRC-009 |
| Многовариантный опрос | В каждый опрос может входить один и более вопросов, каждый с вариантами ответов разных типов | администратор | SRC-009 |
| Сроки опроса | Администратор устанавливает дату начала и конца проведения опроса | администратор | SRC-009 |
| Голосование в опросе | Пользователь может участвовать в опросе, выбрав вариант ответа; повторно проголосовать в том же опросе нельзя | все пользователи | SRC-009, SRC-224 |
| Просмотр результатов опроса | Результаты опроса показываются в виде диаграммы (гистограмма или круговая) | все пользователи | SRC-009, SRC-225 |
| Анонимность опроса | Администратор задаёт уровень анонимности опроса: обычный (решает голосующий), публичный (все голоса видны) или анонимный | администратор | SRC-226 |
| Система благодарностей | Сотрудник может выразить благодарность коллеге определённого типа («Благодарности типа «#GRAT_NAME#»»); действие видно в ленте | все пользователи | SRC-208 |
| Значки достижений | Благодарности делятся на настраиваемые типы, у каждого — своё название/значок | администратор | SRC-208 |
| Доска достижений | В коробке есть раздел «Доска почёта» | все пользователи | SRC-001, SRC-209 |
| Создание форума | Администратор создаёт один и более форумов для обсуждений | администратор | SRC-010 |
| Гибкий контроль доступа в форуме | Администратор может ограничить право читать и постить сообщения в форуме | администратор | SRC-010 |
| Создание темы форума | Пользователь открывает новую тему в форуме для начала обсуждения | пользователи с правом | SRC-010 |
| Модерация сообщений форума | Модератор может проверять сообщения до публикации или удалять нежелательные | модератор | SRC-010 |
| Рейтинг пользователя форума | Система отслеживает активность пользователя в форуме через рейтинг и кол-во сообщений | система | SRC-010 |
| Создание блога | Пользователь может создать свой блог для публикации статей | все пользователи | SRC-011 |
| Неограниченное число блогов | Система позволяет создавать неограниченное число блогов | администратор | SRC-011 |
| Создание записи в блоге | Автор блога пишет новую запись или редактирует существующую | автор блога | SRC-011 |
| Сохранение черновиков | Автор может сохранить черновик записи перед опубликованием | автор | SRC-011 |
| Использование тегов в блоге | Записи помечаются тегами для группировки материалов | автор | SRC-011 |
| Присоединение изображений | Автор может добавить изображения к записи блога | автор | SRC-011 |
| Комментарии к записям | Читатели могут комментировать записи в блоге | читатели | SRC-011 |
| Модерация записей блога | Модератор проверяет запись перед опубликованием | модератор | SRC-011 |
| Обработка смайликов | Система преобразует текстовые смайлики в графические | система | SRC-011 |
| Управление правами доступа к блогам | Администратор может ограничить доступ к блогам | администратор | SRC-011 |
| Фотогалерея | Пользователь может создавать альбомы фотографий (модуль «Фотогалерея 2.0» входит в дистрибутив) | все пользователи | SRC-201 |
