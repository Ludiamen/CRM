# Модуль эталона: Открытые линии / Контакт-центр

## Назначение модуля

Модуль предоставляет возможность управления входящими обращениями от клиентов через различные коммуникационные каналы (чат на сайте, мессенджеры, социальные сети), распределения обращений между операторами и отслеживания качества обслуживания.

## Сущности

| Сущность | Что это | Атрибуты | Связь с другими |
|---|---|---|---|
| Обращение | Диалог с клиентом или внешним контактом | идентификатор, контакт, канал, тема, статус, время создания, очередь | привязана к контакту CRM, может быть переведена в задачу или сделку |
| Канал (Коннектор) | Способ связи с клиентом | тип (онлайн-чат, Telegram, Viber, WhatsApp, Facebook, Instagram, ВКонтакте, Одноклассники и др.), название, конфигурация | используется для получения обращений |
| Очередь | Группа обращений, распределяемых между операторами | название, приоритет, операторы, режим распределения | содержит обращения |
| Оператор | Сотрудник, обслуживающий обращения | имя, доступные каналы, текущая нагрузка | работает с обращениями из назначенной очереди |
| Сообщение | Единица диалога между клиентом и оператором | текст, автор, время, вложения | часть обращения |
| Чат-сессия | Сеанс взаимодействия в реальном времени | участники, история, статус | может быть конвертирована в обращение |

## Экраны и элементы интерфейса

- Настройка открытой линии (срез 012, CAP-29): блок «Очередь» — «Укажите ответственных сотрудников, которые
  будут отвечать на входящие обращения в этой открытой линии. Можно задать способ распределения обращений и
  время, через которую обращение будет автоматически перенаправлено на следующего в очереди» (SRC-372).
- Способ распределения — выбор из трёх значений: «Равномерно», «Строго по очереди», «Одновременно всем»; в
  режиме «Одновременно всем» «активируется бесконечная очередь» (SRC-372).
- «Время до перехода к следующему сотруднику» — от 1 минуты до 12 часов, есть значение «не переводить»
  (SRC-372). Правило при отсутствии ответа включает «Вернуть обратно в очередь» (SRC-372).
- Оценка качества (срез 012, CAP-35): настройки «Отправлять запрос оценки качества обслуживания», «Разрешить
  оценку диалога до его окончания», «Закрывать сессию сразу после оценки», а также тексты запроса, положительной
  и отрицательной оценки (SRC-373). В диалоге клиенту предлагается «Пожалуйста, оцените качество обслуживания»
  и вариант ответа «Отправьте: 1 - хорошо, 0 - плохо» (SRC-373).
- Задача из чата (срез 012, CAP-38): в чате есть пункт «Создать задачу»; созданная задача называется
  «Задача из чата "#CHAT_TITLE#"» (SRC-374).

## Сценарии

- **Распределение обращения.** При поступлении обращение направляется по правилам очереди: «Обращение
  направлено на всех участников очереди» либо «Обращение перенаправлено на #USER_TO# по правилам очереди»;
  если доступных операторов нет — «Обращение возвращено в очередь. Нет доступных операторов» (SRC-372).
- **Возврат в очередь.** Диалог снимается с оператора, когда тот в отпуске, не начал или завершил рабочий день,
  уволен, удалён из линии, недоступен или не в сети (SRC-253, SRC-360). При оффлайне оператора «Сессия
  возвращена в очередь, так как оператор оффлайн» (SRC-360); отказ от диалога невозможен, если в очереди больше
  никого нет (SRC-253).
- **Оценка ответа.** Клиент получает запрос оценки при закрытии диалога и отвечает «1 - хорошо, 0 - плохо»
  (SRC-373). Оценка возможна ограниченное время: после него показывается «К сожалению, время для оценки диалога
  закончилось (#DAYS#)» (SRC-373). Отчёт считает обращения с положительной и отрицательной оценкой, без оценки
  и «Процент довольных клиентов» (SRC-373).
- **Задача из обращения.** «Нажмите на скрепку и выберите, что хотите создать: задачу или встречу» (SRC-111);
  созданная из чата задача получает название «Задача из чата "#CHAT_TITLE#"» (SRC-374).

## Связи с другими модулями

- **CRM** — контакты и сделки из CRM связаны с обращениями
- **Задачи** — из чата обращения создаётся задача с названием «Задача из чата "#CHAT_TITLE#"» (SRC-374);
  видна ли связь задачи с обращением с обеих сторон, проверенными источниками не подтверждено
- **Техподдержка** — обращения можно направлять в систему техподдержки
- **Бизнес-процессы** — интеграция обращений с автоматизированными процессами

## Возможности — кандидаты в карту эталона

| Возможность | Что делает | Используют | Источник |
|---|---|---|---|
| Прямая интеграция мессенджеров | Получение сообщений из Telegram, Viber, WhatsApp и других мессенджеров в одном интерфейсе | операторы, клиенты | SRC-255 |
| Интеграция с социальными сетями | Приём обращений из Facebook, Instagram, ВКонтакте, Одноклассников и других соцсетей | операторы, клиенты | SRC-255 |
| Живой чат на сайте | Встроенный чат для посетителей сайта компании (канал «Онлайн-чат») | клиенты, операторы | SRC-255, SRC-252 |
| Распределение обращений | Автоматическое распределение обращений между операторами очереди: «Равномерно», «Строго по очереди», «Одновременно всем»; при недоступности оператора диалог возвращается в очередь; при отсутствии ответа срабатывает правило «Вернуть обратно в очередь» | диспетчер, система | SRC-112, SRC-253, SRC-372 |
| Управление очередями | Настройка режима распределения, времени до перехода к следующему сотруднику (1 минута — 12 часов или «не переводить») и правила при отсутствии ответа | администратор, супервизор | SRC-112, SRC-253, SRC-372 |
| История диалога | Сохранение переписки в рамках сессии обращения и истории предыдущих диалогов клиента | операторы, клиенты, аналитики | SRC-253 |
| Автоматические сообщения | Система отправляет приветственное сообщение при начале диалога, сообщение при долгом отсутствии ответа оператора и сообщение о нерабочем времени | администратор, система | SRC-254 |
| Оценка качества обслуживания | Клиент может поставить оценку ответам оператора («Оценки» диалога): запрос при закрытии, ответ «1 - хорошо, 0 - плохо», ограниченный срок оценки; отчёт считает положительные, отрицательные и неоценённые обращения | клиент, супервизор, аналитики | SRC-253, SRC-373 |
| Интеграция с CRM | На основе обращения и контактных данных клиента создаётся или дополняется лид, контакт или компания в CRM | операторы, менеджеры | SRC-252 |
| Создание задач из обращений | Оператор может поставить задачу или встречу прямо из чата обращения, не покидая диалог; пункт меню «Создать задачу», название задачи «Задача из чата "#CHAT_TITLE#"» | операторы, менеджеры | SRC-111, SRC-374 |
| Перенаправление обращения | Оператор вручную передаёт диалог другому сотруднику или в другую очередь (линию); если оператор оффлайн, сессия возвращается в очередь | операторы, диспетчер | SRC-360 |
