# Отчёт проверки PLAN-002 (план среза 002 «Оргструктура»)

Вердикт: **годен к подписи.** Блокирующих и важных находок нет. Все находки
трёх партий внесены или решены иначе осознанно; изменения черновика полностью
объясняются скриптом Opus и одной редакционной заменой. Остались две мелочи
(раздел «Находки для Opus»), ни одна не мешает подписи.

## Метод
1. Три партии проверили черновик по шаблону: P1 (строки 1–203; 0 блокирующих,
   3 важных, 4 мелочи, 3 вопроса), P2 (до строки 382; 0 / 7 важных / 7 мелочей,
   8 вопросов), P3 (строки 383–706; 0 / 4 важных / 9 мелочей, 4 вопроса).
2. Opus применил решения скриптом `opus_apply.py` (одна замена на тег, ровно
   одно совпадение), затем одну редакционную замену и перенос строк по 80 знаков
   (`reflow.py`).
3. Итоговая проверка (свежий проверяющий): пословное сравнение снимка и плана;
   сверка находок и решений; сверка новых утверждений с первоисточниками;
   сквозные проверки согласованности; ворота и тесты.

`crm-work/slice002/plan-review/opus_apply_F.py` (три пары, по одному совпадению
на пару), затем перенос строк `reflow.py`. Механическая сверка: пословное
сравнение плана до и после правки (difflib) даёт ровно три замены этих пар и
ничего больше:
- «восемь простых списков функций» → «девять …» (F1);
- пункт меню «Календарь» — право `staff.view` или `calendar.manage` (F2, пара 1);
- «одно из» прав в ядре — для списка, карточки, выдачи фото и страницы
  календаря (F2, пара 2).
