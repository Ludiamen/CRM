### Находки для Opus
Блокирующих нет.

Важные.
1. SRC-367 (строка реестра): назван один файл триггера `expiredsoon.php` без ключей, а триггер «Просрочена» лежит в другом файле — `trigger/expired.php` (`TASKS_AUTOMATION_TRIGGER_EXPIRED_NAME` = «Просрочена»), которого в строке нет. ADR опирается на SRC-367 («автоматика стадий умеет отслеживать «Скоро просрочена» и «Просрочена»»), значит часть опоры в строке не названа. Подробности — в отчёте REF-SRC.
2. «Конституция не меняется: Web Push подпадает под инварианты …» (последнее предложение). Текст «пдн-152фз» называет внешними каналами только Telegram и MAX, «интеграции-через-адаптеры» перечисляет почту, Telegram/MAX, Zabbix, АСДОБ. Распространение на Web Push — толкование Opus (владелец в тексте варианта сам написал «По правилу 152-ФЗ из конституции в Web Push уходит только событие и ссылка», так что по существу оно им принято). Предложение: пометить как вывод Opus и при следующем перевыпуске конституции дописать Web Push в перечни.

Мелкие.
3. Решение 3: пометка «(вывод Opus)» стоит в конце длинного предложения и по тексту может читаться как относящаяся только к «сводки — по ответу 4». Лучше поставить пометку сразу после «общая для всех модулей».
4. В «Альтернативах» довод «заметно больше работы, чем просил владелец» — слова варианта Q1 («заметно увеличит работу»), но «чем просил владелец» — вывод Opus; доводы в разделе названы доводами Opus, так что допустимо.
5. Срез 004 после ADR-0010 заметно больше исходного состава (каталог видов, четыре канала, Web Push, отложенная отправка, сводки). ADR-0004 говорит «Итого 34 возможности» — число не меняется, но разбивать срез на подсрезы или нет, решит спека 004; стоит напомнить об этом при её подготовке.

### Что не проверялось
Техническая реализуемость Web Push (поддержка Яндекс.Браузером, лицензии библиотек) — в ADR вынесена на план среза 004. Состав среза 004 в спеке (спеки 004 ещё нет).
