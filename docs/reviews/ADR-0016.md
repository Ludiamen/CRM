# Отчёт проверки ADR-0016 (пересмотр срока NFR-403)

## Что проверено

- ADR-0016 оформлен в `docs/decisions/0016-kb-preview-nfr403.md`, зависит от утверждённых ADR-0012, TGT-NFR, CONST.
- Замер пересчитан и перепроверен: обычный текст 200 000 знаков на остывшем стенде рендерится ~1,05–1,07 с
  (лучшее из трёх), что на 5–7 % выше бюджета NFR-403 (≤ 1 с). Регрессии кода нет — это оптимистичный порог.
- Решение владельца получено отдельно: установить срок **1,5 с** (обычный текст), патологический Markdown
  остаётся вне срока (решение плана `plan.md:925`). Иначе бюджет не меняется.

## Соответствие конституции

Правило спеки «значения можно ужесточать, ослаблять нельзя» (`spec.md:807`) не нарушается самовольно: ослабление
зафиксировано отдельным ADR и подтверждено решением владельца. Смотритель-ворота учитывает ADR как основание.

## Ограничения

Отчёт подтверждает оформление и факты ADR, подпись ставит владелец. Последующие правки спецификации SPEC-005
(значение NFR-403) и порогов тестов `test_kb_render.py`, `test_k12_criteria.py` — следствия решения, выполняются
после подписи ADR.
