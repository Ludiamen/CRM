# Словарь

| Термин | Смысл |
|---|---|
| Заявка | обращение работника общества в ИТ-отдел; приходит письмом, через открытую форму или из мониторинга |
| Заявитель | работник общества, который пишет в ИТ; учётной записи на портале у него нет |
| Исполнитель | сотрудник ИТ с учётной записью, который работает по заявке или задаче |
| Очередь | группа исполнителей и заявок одного направления («Сеть», «1С», «Рабочие места»); состав настраивается без кода |
| SLA | нормативные сроки реакции и решения заявки, считаются по рабочему календарю |
| Задача | внутренняя работа отдела (не обращение заявителя); может входить в проект |
| АСДОБ | система документооборота общества на базе 1С:Документооборот; расшифровку и роль в портале уточняет владелец (Q-001) |
| Эталон | «1С-Битрикс: Корпоративный портал» (коробка) — образец поведения и интерфейса, не образец кода |
| Источник (SRC-NN) | страница документации 1С-Битрикс или снимок экрана демо, на который опирается утверждение об эталоне |
| Возможность (CAP-NN) | одна функция эталона или своя функция в карте возможностей; у каждой — решение MVP / позже / не нужно |
| Приём интерфейса (UX-NN) | повторяющийся элемент поведения интерфейса Битрикса: слайдер карточки, канбан, живой счётчик и т.п. |
| Срез | вертикальный кусок системы (спека → план → задачи → код), который можно показать пользователю целиком |
| Ворота | условия перехода документа в следующий статус; проверяет `tools/sdd.py`, подписывает человек |
| Отпечаток | sha256 тела документа; подпись действует, пока отпечаток не изменился |
| Двухфакторная авторизация | вход по паролю плюс одноразовый код (TOTP); обязательна для всех учётных записей |
